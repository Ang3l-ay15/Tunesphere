# 🎵 TuneSphere — Music Academy Website

A responsive music academy website designed to showcase music courses, instruments, pricing plans, and learning opportunities for aspiring musicians.

🔗 **Live Demo:** https://ang3l-ay15.github.io/Tunesphere/

## 📌 About the Project

TuneSphere is a front-end website project for a fictional music academy. It presents music lessons and learning opportunities through a structured interface featuring course information, instrument sections, testimonials, pricing plans, and contact options.

The project focuses on responsive web design, content presentation, and creating a professional website for a music education business.

## ✨ Features

- **Responsive Design:** Layout adapts to different screen sizes.
- **Navigation Bar:** Links to Home, About, Courses, Gallery, Pricing, and Contact.
- **Hero Section:** Introduces the academy and provides calls to action.
- **About Section:** Presents information about the music academy.
- **Music Courses:** Showcases instruments and learning options, including:
  - Saxophone
  - Keyboard
  - Guitar
  - Drums
  - Vocals
  - Violin
- **Statistics Section:** Highlights academy-related statistics.
- **Why Choose Us:** Presents benefits such as expert tutors, flexible schedules, online classes, and certification.
- **Testimonials:** Displays student feedback.
- **Gallery:** Provides a visual section for music-related content.
- **Pricing Plans:** Presents lesson and course pricing options.
- **Enrollment Calls to Action:** Encourages visitors to explore courses or request a trial class.
- **Contact Interface:** Includes a contact form layout and contact information.
- **Newsletter Interface:** Includes an email input for newsletter subscriptions.

> **Note:** The contact and newsletter forms are front-end interfaces only. Form submissions are not connected to a backend or email service, so they do not send or store submitted information.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 📱 Responsiveness

TuneSphere is designed to adapt to different screen sizes, helping visitors browse the academy's content on desktop and mobile devices.

## 🚀 Getting Started

To view the project locally:

1. Clone or download this repository.
2. Open the project folder.
3. Locate `index.html`.
4. Open `index.html` in your web browser.

No backend setup is required to view the website.
